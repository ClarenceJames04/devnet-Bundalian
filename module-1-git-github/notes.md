## What is Git? What is GitHub? (explain like you're teaching a friend who's never used either)

[Git is a tool that saves the changes you make in your project. It helps you keep different versions and recover old work if needed. GitHub is a website where you upload and share your Git projects. It is useful for backup and group collaboration. Git works on your computer, while GitHub stores your project online.]

---

## Key vocabulary (in your own words)

- repository: A folder where your project and its files are stored.
- commit: Save the changes
- branch: Seperate your work to another user
- push / pull: Push uploads your changes to GitHub. Pull downloads the latest changes
- pull request: Add your changes to the project
- merge conflict: A error which two people edit the same file
